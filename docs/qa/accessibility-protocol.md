# بروتوكول اختبار الإتاحة — المستديرة

> **هذه أداة تُشغَّل، لا نتائج.** كُتبت لأن مَن كتبها **لا يملك جهازًا ولا قارئ شاشة**،
> فكلّ خلية «ما حدث فعلًا» و**كلّ جدول النتائج فارغ عمدًا** — يملؤه المختبِر.
> ووجودُ `aria-label` في المصدر **ليس نجاحًا**: النجاح أن يُكمِل المستخدم المهمّة.

---

## التجهيز

| | |
|---|---|
| الجهاز | أندرويد حقيقي (لا محاكي — الاهتزاز وTalkBack يختلفان) |
| النسخة | `Desktop\المستديرة-التطبيق.apk` بعد **حذف القديمة** (توقيعا debug/release متعارضان) |
| قارئ الشاشة | TalkBack — الإعدادات ⇒ إمكانية الوصول ⇒ TalkBack |
| لوحة المفاتيح | لوحة بلوتوث أو USB-OTG (لمسار «د») |
| اللغتان | كرّر كل مسار بالعربية **والإنجليزية** — الخلل الاتّجاهي لا يظهر إلّا في اتجاه واحد |
| الثيمان | مرّة نهاري ومرّة ليلي حيث يُذكَر التباين |

**إيماءات TalkBack:** مسح يمين/يسار = العنصر التالي/السابق · نقر مزدوج = تفعيل ·
مسح لأعلى ثمّ يمين = القائمة · إصبعان لأعلى = قراءة من الأعلى.

⚠️ **أعِد ضبط الحالة بين المسارات:** «أعِد عرض شاشات الترحيب» في الحساب ⇐ التفضيلات
(إن نُفِّذت الدفعة ٧)، وإلّا فامسح تخزين التطبيق.

**تدوين الأعطال:** اكتب في «ما حدث فعلًا» ما **سمعتَه حرفيًّا** لا تقييمك له، ثمّ
صنّف: `Blocker` / `Major` / `Minor` / `✓`.

| أ‑٢١ | سطر التقييم بجانب الاسم | يُنطق رقمًا وعددًا، **ومكانٌ بلا تقييم لا يُنطق شيئًا** (لا «0 من 0») | |
| أ‑٢٢ | زرّا الاتصال والخريطة | لكلٍّ اسم صريح، والغائب منهما لا يترك عنصرًا فارغًا | |

| أ‑٣٣ | زرّ التأكيد | يُنطق، وأثناء الإرسال تُعلَن حالة الانتظار لا صمت | |

## د · التكافؤ بلوحة المفاتيح

**كرّر الجدول كاملًا في `dir=rtl` ثمّ في `dir=ltr`.**

| # | المكوّن | المتوقَّع | ما حدث فعلًا (RTL) | ما حدث فعلًا (LTR) |
|---|---|---|---|---|
| د‑١ | الصفحة كلّها | Tab يمرّ بكل تفاعلي **بترتيب بصري**، وShift+Tab يعكسه | | |
| د‑٢ | كل عنصر مركَّز | **حلقة تركيز مرئية** — واضغط Tab فعلًا، لا `el.focus()` | | |
| د‑٣ | `#detailTabs` | Tab يدخل المجموعة **مرّة واحدة**؛ الأسهم تتنقّل؛ Home/End للطرفين | | |
| د‑٤ | `#matchPick` | كما أعلاه (radiogroup) — والتحرّك **يختار** | | |
| د‑٥ | `.pay-pick` | كما أعلاه، و«فيزا» **تُركَّز ولا تُختار** | | |
| د‑٦ | `#modeSeg` | كما أعلاه | | |
| د‑٧ | `.onb-seg` | كما أعلاه | | |
| د‑٨ | 🔴 اتجاه الأسهم | في RTL: **السهم الأيسر = التالي** والأيمن = السابق. في LTR بالعكس | | |
| د‑٩ | نقاط شاشات الترحيب | أسهم بالاتجاه الصحيح | | |
| د‑١٠ | أي نافذة (modal) | Escape يغلق · التركيز محبوس داخلها · يعود إلى فاتحها عند الإغلاق | | |
| د‑١١ | ورقة الفلاتر | كما أعلاه، وEnter على «تطبيق» يطبّق | | |
| د‑١٢ | شبكة الأوقات | Tab يصل كل زرّ، وEnter/Space يفعّل | | |
| د‑١٣ | `<summary>` كلمة السرّ | Tab يصله · Enter/Space يفتح · **حلقة تركيز مرئية** | | |
| د‑١٤ | القوائم (`<select>`) | تُفتح بلوحة المفاتيح وتُختار وتُغلق | | |
| د‑١٥ | «تخطٍّ إلى المحتوى» | أوّل Tab في الصفحة، **ويظهر عند التركيز** | | |
| د‑١٦ | الشريط السفلي | Tab يصل الأزرار الأربعة، وEnter ينقل | | |

### التعريفات

- **Blocker** — المستخدم **لا يستطيع إكمال المهمّة**.
- **Major** — يُكمل لكنّه **لا يفهم حالة أو معلومة لازمة للقرار**.
- **Minor** — إرباك لا يمنع المهمّة.

**معيار النجاح: لا Blocker متبقٍّ.**
