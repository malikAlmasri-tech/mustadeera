# المستديرة — خريطة المشروع

منصّة حجز ملاعب كرة قدم. **نسختان من نفس المنتج:** موقع للمتصفّح، وتطبيق أندرويد مدمج
(Capacitor). واجهة ثنائية اللغة (عربي RTL / إنجليزي LTR)، بلا أي مكتبة JS.

> **هذا الملفّ يقول: أين كل شيء وأين أُحرّر.**
> لحالة العمل الحالية وما تبقّى ⇐ [`CLAUDE.md`](CLAUDE.md).

---

## ⚡ أين أُحرّر — القاعدة الوحيدة التي تمنع أكثر الأخطاء شيوعًا

**الموقع والتطبيق مفصولان تمامًا. لكلٍّ ثلاثيّه الخاص.** تعديل في أحدهما لا يصل إلى الآخر.

| أريد أن أعدّل… | أحرّر هذه الثلاثة | ولا ألمس |
|---|---|---|
| **التطبيق** (الهاتف) | `app/native/app.html` + `app/native/app.css` + `app/native/app.js` | ملفّات `app/` المباشرة |
| **الموقع** (المتصفّح) | `app/index-new.html` + `app/style-new.css` + `app/app.js` | أي شيء في `app/native/` |

> ⚠️ **ثمن الفصل:** إصلاح منطق يخصّ الاثنين يُطبَّق **يدويًّا في الملفّين**. لا يوجد مصدر مشترك.

**بعد أي تعديل، شغّل البناء دائمًا:**

```bash
powershell -ExecutionPolicy Bypass -File app\build.ps1
```

## 🤖 ملفّات مولَّدة — لا تُحرّرها، ستُمحى

`build.ps1` يكتبها. أي تعديل يدوي فيها يضيع عند أوّل بناء:

| الملفّ | ما هو |
|---|---|
| `index.html` (الجذر) | بناء **الموقع** — وهو **الملفّ الوحيد الذي يتتبّعه git** وينشره Vercel |
| `المستديرة محدث.txt` | نسخة مطابقة للسابق (اسم قديم أُبقي للتوافق) |
| `www/index.html` | بناء **التطبيق** — يُدمج داخل الـAPK |
| `app/_preview_mohdath.html` | معاينة الموقع |
| `app/native/_preview_app.html` | معاينة التطبيق |

## ⚠️ حالة `Code.gs`

الباكند القديم على Google Apps Script + Google Sheets. **التطبيق لم يعد يستعمله**
(انتقل إلى Postgres/Supabase)، لكن **الموقع ما زال عليه** حتى تُنفَّذ الخطة ②.

**لا تصرف وقتًا على تطويره.** يبقى منشورًا كشبكة أمان فقط، ويُوقَف في نهاية الخطة ②.

## 🔒 ما لا يُرفع إلى git أبدًا

مضبوط في [`.gitignore`](.gitignore): مفتاح التوقيع (`*.jks`) وكلمات سرّه
(`android/keystore.properties`) و`node_modules/` ومخرجات البناء.

**من يملك مفتاح التوقيع يستطيع نشر تحديث يبدو صادرًا عنك على جهاز كل مستخدم.**
تحقّق بـ`git status --short` قبل أي دفعة.
