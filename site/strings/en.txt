# ---------- (2.3) Venue application data ----------
privJoinTitle = Venue applications
privJoinBody = If you fill in the "Register your venue" form we store what you wrote: your name and number, the venue's name, city, area, sport and number of courts, and your note if you left one. We use it to contact you about that application only. The row is readable by platform administrators alone - enforced by the database itself, not by the page. A rejected application keeps its reason so there is an answer if you ask later, and we delete it on request.

# ---------- (3.3) Usage measurement ----------
privUsageTitle = Usage measurement
privUsageBody = We record five events so we can see where we fall short: a search that returned nothing (with the search term), opening a venue page, reaching the review step, sending a request, and tapping "tell me if it frees up". None carries your name, your number, your location, or any text you type other than the search term. The event is linked to your account when you are signed in - to tell one visit from ten, nothing more - and only platform administrators can read these rows: not venue owners, not other users. If you ask to be told about a slot we store it so we can notify you when it opens, and nobody but you can see it.
